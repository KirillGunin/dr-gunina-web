# SEO-аудит dr-gunina.ru

Дата: 13 августа 2026. Основано на разборе кода репозитория (`nuxt.config.ts`, `app/composables/seo-*.ts`, `app/pages/`, `server/routes/sitemap-urls/`).

---

## Главный вывод

Сайт сейчас не может ранжироваться — не потому что «мало ссылок», а потому что для поисковика он состоит из **4 индексируемых страниц без заголовков H1 и без единого ключевого слова в правильных местах**. Плюс два технических блокера, из-за которых Google может вообще не видеть русскую версию.

Отдельно по вашему запросу «онлайн консультация педиатра»: это федеральный коммерческий запрос, топ-10 в нём занят агрегаторами (ПроДокторов, НаПоправку, Гемотест, Genotek, клиника Фомина) с доменным рейтингом 70–90 и десятками тысяч страниц. **Сайт одного врача туда не выйдет ни за год, ни за два.** Но рядом есть три ниши, где выдача почти пустая — про них в конце.

## 1. Блокеры (пока не исправлено — остальное бессмысленно)

### 1.1 На главной странице нет H1

`app/pages/index.vue` — самый крупный заголовок на странице это `<h4>Обо мне`. Хук «Обошли всех врачей, но так и не поняли, что с ребёнком?» выводится в `<span>`.

Для поисковика главная страница не имеет темы. Ни Яндекс, ни Google не понимают, о чём она.

Нужен `<h1>` вида «Онлайн-консультация педиатра, аллерголога и дерматолога» + иерархия H2 по секциям (обо мне / услуги / отзывы).

### 1.2 Нет аналитики вообще

Ни Яндекс.Метрики, ни GA4, ни GTM (`grep` по проекту — ноль совпадений).

Два последствия:
- Вы работаете вслепую: не видно, по каким запросам приходят, где отваливаются.
- **Для Яндекса это прямой минус в ранжировании.** Поведенческие факторы — один из главных сигналов Яндекса, и Метрика их поставляет. Сайт без Метрики Яндекс оценивает хуже.

Метрика — задача на 20 минут, эффект самый быстрый из всего списка.

### 1.3 Не задан `site.url` — sitemap собран некорректно

`@nuxtjs/sitemap` подключён, но в `nuxt.config.ts` нет блока:

```ts
site: { url: 'https://dr-gunina.ru', name: '...' }
```

Без него модуль не знает канонический домен и не может корректно построить абсолютные URL и `xhtml:link` hreflang-альтернативы в самом sitemap. `robots.txt` при этом ссылается на `https://dr-gunina.ru/sitemap.xml` — стоит открыть его в браузере и проверить, что там за ссылки.

### 1.4 `detectBrowserLanguage` включён по умолчанию — риск потери русской главной в Google

В `nuxt.config.ts` блок `i18n` не отключает автоопределение языка. В `@nuxtjs/i18n` v10 оно **включено по умолчанию** с `redirectOn: 'root'`.

Googlebot краулит преимущественно из США с заголовком `Accept-Language: en`. То есть при заходе на `https://dr-gunina.ru/` его может редиректить на `/en/`. Русская главная — ваша основная посадочная — рискует не попасть в индекс Google.

Лечится явным отключением:

```ts
i18n: {
    detectBrowserLanguage: false,
    // ...
}
```

Проверить: в Google Search Console → «Проверка URL» для `https://dr-gunina.ru/` посмотреть, какой HTML видит Googlebot.

### 1.5 Четыре индексируемые страницы

Всё, что есть: `/`, `/pollen`, `/privacy`, `/services/[service]`. Минус `/privacy` (не ранжируется), минус админка. Реально бороться за трафик могут ~2 страницы плюс карточки услуг.

Конкуренты в этой выдаче имеют 500–50 000 страниц. Это не про «догнать по объёму» — это про то, что **у вас нет ни одной страницы, целиком посвящённой запросу «онлайн-консультация педиатра»**.

## 2. Контент и семантика

### 2.1 Title главной начинается с того, что никто не ищет

Сейчас:

> `Гунина Ксения Александровна — педиатр, аллерголог, дерматолог`

Первые 30 символов title — самый весомый участок. Вы отдали их под ФИО, которое ищут только те, кто вас и так знает. Ключевой запрос в title отсутствует полностью.

Вариант:

> `Онлайн-консультация детского врача — педиатр, аллерголог | Гунина К.А.`

То же самое с `ogTitle` и `twitterTitle`.

### 2.2 Title страниц услуг подставляется из API как есть

`app/composables/seo-service.ts`:

```ts
title: () => service.value?.title
```

Что придёт из API, то и станет `<title>`. Если это «Информационная услуга» — страница не ранжируется ни по чему. Нужен шаблон: `${service.title} — онлайн у детского врача | Гунина К.А.`, и отдельное SEO-поле `meta_title` / `meta_description` в админке, а не переиспользование `content`.

### 2.3 `description` = `service.content`

Тот же файл: `description: () => service.value?.content`. Описание услуги почти наверняка не укладывается в 150–160 символов и не написано как сниппет. Сниппет — это рекламный текст с призывом, а не первый абзац страницы.

### 2.4 Тонкий контент на страницах услуг

Судя по шаблону `app/pages/services/[service].vue`, страница — это картинка, `h1`, один абзац `content`, список `details`, теги, цена, кнопка. Это 60–120 слов. Конкуренты по этим же запросам держат 1500–3000 слов с FAQ, ценами, описанием процесса.

### 2.5 Нет блога и вообще информационного раздела

Для сайта одного врача это **основной канал роста**, а не опция. Коммерческий запрос вы у агрегаторов не отберёте, а информационные — вполне: «сыпь у ребёнка при прикорме», «догоняющий график прививок как составить», «атопический дерматит у грудничка что делать». Такие запросы приводят ровно ту аудиторию, которая через 2–3 статьи покупает консультацию.

### 2.6 Нет гео-страниц

В JSON-LD у вас прописан очный приём в Гатчине, но **страницы под «педиатр Гатчина» / «детский аллерголог Гатчина» не существует**. Это самая недооценённая позиция в списке: конкуренция там низкая, а вы уже физически там принимаете.

### 2.7 Сертификаты не подтверждены

`app/pages/index.vue`, массив `facts` — у всех элементов `link: ''`. То есть «Член EAACI, WAO и Союза Педиатров России» — просто текст без пруфов. В локали есть ключ `pages.facts.certificate`, но он не используется.

Для медицинской тематики это прямой удар по E-E-A-T: и Google (YMYL-политика), и Яндекс (Проксима) требуют подтверждаемой экспертности. Нужна отдельная страница с дипломами, сертификатами, номером в реестре — сканы, а не текст.

## 3. Микроразметка Schema.org

Разметка сделана подробно и это сильная сторона проекта. Но в продакшене есть ошибки, из-за которых часть графа невалидна.

### 3.1 Плейсхолдер `ВАШ_ДОМЕН` уехал в прод

`app/composables/seo-index-ru.ts`, три места:

```
'@id': 'https://ВАШ_ДОМЕН/#website'
url: 'https://ВАШ_ДОМЕН/'
provider: { '@id': 'https://ВАШ_ДОМЕН/#physician' }   // у курса «Про прикорм»
```

Плюс закомментированный `//url: 'https://ВАШ_ДОМЕН/ru/vakcinaciya'` у курса «Без паники». Узел `WebSite` сейчас невалиден, и связь курсов с врачом разорвана.

### 3.2 `@id` у клиник не являются URI

```
'@id': 'practice1'
'@id': 'practice-2'
```

Должно быть `https://dr-gunina.ru/#practice-1` и `#practice-2`.

### 3.3 Ссылки в Offer ведут на картинки

```
url: 'https://dr-gunina.ru/images/services/consultation.png'
```

`url` в `itemOffered` должен вести на страницу услуги (`/services/...`), а картинка идёт в `image`. Сейчас поисковик получает указание, что «страница услуги» — это PNG-файл.

### 3.4 Клиники не связаны с врачом

Два узла `MedicalBusiness` висят в графе отдельно от `Physician`. Нужна явная связь — `worksFor` со стороны врача или `employee` со стороны клиники, иначе Google не соберёт единую картину «врач принимает вот в этих двух местах».

### 3.5 Опечатка в тексте разметки

`'Групповой чат поддержки для родителей с пидеатром...'` — «пидеатром». Это уходит в `name` схемы и, вероятно, есть в самой БД.

### 3.6 Чего не хватает

- **`BreadcrumbList`** на страницах услуг — Яндекс и Google выводят хлебные крошки в сниппете, это заметно поднимает CTR.
- **`FAQPage`** — в медицинской тематике Яндекс охотно показывает быстрые ответы.
- **`aggregateRating`** — но добавлять самостоятельно **не советую**: Google с 2019 года игнорирует self-serving отзывы для `Physician`/`LocalBusiness`. Рейтинг нужно набирать на ПроДокторов и Яндекс.Картах, а не размечать у себя.

### 3.7 Разметка `Review` — нюанс

`app/composables/seo-reviews.ts` формирует граф отзывов корректно, но по той же причине (self-serving) Google их к звёздам в выдаче не применит. Яндекс относится лояльнее, так что оставлять стоит — просто без завышенных ожиданий.

## 4. Внешние факторы

Для медицины это половина успеха, а у вас здесь тоньше всего.

Что уже есть (по `sameAs`): МедиКом+, ПроДокторов, НаПоправку, ВК, Zoon. Это хорошая база.

Чего нет или не проверено:
- **Яндекс.Бизнес / Яндекс.Карты** — карточка с адресом приёма в Гатчине. Для запроса «педиатр Гатчина» это фактор №1, важнее всего сайта целиком.
- **Google Business Profile** — то же для Google.
- Число и свежесть отзывов на ПроДокторов. По этим агрегаторам вас найдут раньше, чем по сайту, и они же передают траст на домен.

## 5. Как оценивать конкурентов

Метод, а не разовая проверка.

**Шаг 1. Разделить выдачу на классы.** Вбейте запрос и разметьте топ-10: агрегатор / клиника / частный врач. Если 8 из 10 — агрегаторы, запрос вам не подходит, ищите формулировку, где появляются частные врачи. Это главный фильтр при подборе семантики.

**Шаг 2. Взять только сопоставимых конкурентов** — сайты отдельных врачей в топе. Смотреть у них: сколько страниц в индексе (`site:домен` в Яндексе), есть ли блог и как часто выходит, длину текста на коммерческой странице, есть ли FAQ, что в title.

**Шаг 3. Снять данные инструментами.** Яндекс.Вордстат — частотность и, главное, фразы-хвосты. Букварикс или Keys.so — по каким запросам конкурент уже виден. Ahrefs/Serpstat на пробном тарифе — ссылочный профиль: откуда берут ссылки врачи, а не клиники.

**Шаг 4. Искать не «как обойти», а «где их нет».** Обойти ПроДокторов по «онлайн консультация педиатра» нельзя. Но у агрегаторов принципиально нет: авторской экспертизы, работы на конкретном языке для конкретной страны, узких тем.

## 6. Где реально можно выйти в топ

Проверил выдачу — три ниши практически свободны:

**Русскоязычные родители за границей.** Поиск по «русскоязычный педиатр онлайн консультация Испания» не даёт ни одного специализированного сервиса — только общие статьи «Испания по-русски» и российские агрегаторы, которые под эту аудиторию не заточены. У вас в разметке уже стоит `areaServed: Russia, Spain, Argentina` и `knowsLanguage: ru, en, es`, локали ru/es/en готовы. Инфраструктура есть, страниц под запрос — нет. Это самая быстрая победа.

**Гатчина и ЛО.** Локальная выдача + Яндекс.Бизнес. Вы там принимаете очно, конкурентов единицы.

**Менторство для врачей.** Услуга в прайсе есть, страницы нет, выдача по «менторство для педиатров» почти пустая. B2B-запрос с высоким чеком и нулевой конкуренцией.

Федеральный коммерческий запрос «онлайн консультация педиатра» — это не цель на ближайший год. Он придёт сам, побочным эффектом, когда домен наберёт траст на трёх нишах выше.

| 8 | Отдельные SEO-поля для услуг в API/админке | ~день | 2–3 мес |
